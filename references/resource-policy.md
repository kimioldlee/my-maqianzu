# 资源降级与更新边界

## 资源未挂载

完整安装应保持 `SKILL.md`、`references/`、`scripts/`、索引和 `work/` 的相对关系。平台只挂载 `SKILL.md` 不代表语料为空，只表示本次没有本地全文库。

资源缺失时可尝试公开节目入口或已认证的仓库内容。私有 GitHub 的未认证 Raw 链接不可靠。只有实际打开正文才可称为原文依据；否则写“当前未执行全文检索”或“依据索引定位，未回读正文”。

没有全文语料时仍可完成当前事实核验和框架分析，但必须降低归因强度，不得声称节目曾明确表达相关观点。

## 更新边界

日常新闻分析不自动同步上游、重抓知乎、替换原文、重建索引、提交或推送 Git。只有用户明确要求更新语料或已有自动化授权运行时才执行更新。

更新后核验：

- 新语料文件数量与索引数量一致。
- 检索器能读取更新后的根目录。
- 旧语料在失败时仍可恢复。
- 登录态、Cookie、浏览器 profile 和 session 文件未进入 Git。

更新失败时保留上一个有效版本。Windows PowerShell 脚本只是维护工具，不得成为 macOS 或账号上传技能的运行前提。
