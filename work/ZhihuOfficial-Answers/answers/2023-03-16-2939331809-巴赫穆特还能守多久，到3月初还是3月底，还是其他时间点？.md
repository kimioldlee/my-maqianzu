# 巴赫穆特还能守多久，到3月初还是3月底，还是其他时间点？

- 链接：https://www.zhihu.com/question/584982335/answer/2939331809

两边都用着苏联武器，应该已经意识到3月底这个时间点的意义了——斯大林格勒战役从1942年7月开始，1943年2月结束，历时7个月。

而巴赫穆特攻城战从2022年8月开始，到3月底也是7个月。

顿兵坚城之下，久攻不克，而对方还在不断积累预备队，这不是好兆头。战术问题上升到战略问题之后，必须要考虑一点政治和军心了。
